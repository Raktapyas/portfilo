## ▚ SUMMON THE RITUAL

A single static file. No build step, no dependencies, no server required.

```bash
git clone https://github.com/Raktapyas/portfilo.git
cd portfilo
xdg-open index.html       # macOS: open index.html
```

Prefer a local server? `python3 -m http.server 8000` and visit
`http://localhost:8000`.

The gate opens when you **speak “namaste”** into the microphone — Chrome or Edge,
mic permission required. No microphone, no patience for permission prompts? Type
`namaste` while the gate is up and it will open anyway.

Inside, type `help` for the list of rites. `work`, `skills`, `chronicle`,
`contact`, `resume`. There are also a few commands I did not document.
