What is RAKTAPYAS?

RAKTAPYAS is the working alias of Basudev Dhakal, a full-stack / backend developer based in Nepal. The name is a banner, not a mystery: six years of production Laravel, typed into a terminal at blade speed.

Current post: Megasoft Pvt. Ltd., 2020 → present. The work spans enterprise platforms, high-security back offices, international service portals and e-commerce systems — shipped, indexed and still running.

  • Laravel core architecture, Eloquent modelling and Breeze / Sanctum auth.
  • Filament (TALL) admin consoles with custom metrics, filters and CRUD.
  • Docker & Laravel Sail runtimes; Linux-native workflow on LazyVim.
  • MySQL & PostgreSQL schema isolation, query surgery and optimisation.
  • Vue.js + Tailwind CSS frontends wired to blade-speed backends.
  • Ten live production artifacts across logistics, commerce, health and travel.
